# アプリ本体のライセンスを公開者が選択してください

この配布物では、アプリ本体にMIT等のライセンスをまだ適用していません。GitHubに置くことと、他者に改変・再配布を許可することは別の判断です。

小さなWebアプリのコードを広く再利用してもらいたい場合には、MIT Licenseが候補になります。`LICENSE-MIT.template.txt` は選択した場合に使うための未適用テンプレートです。著作権者・年を確認し、内容に同意したうえで、公開者の判断でルートの `LICENSE` にしてください。別のライセンスを選ぶ場合は、その条件を確認してください。

第三者ファイルには各ファイルの既存ライセンスが引き続き適用されます。アプリ本体のライセンスでPDF.js・フォント・利用者のPDFを一括して再許諾するものではありません。

地図やPDFを本体に同梱しない構成にしていますが、利用者が選んだPDFに関する著作権・契約上の問題がなくなることを保証するものではありません。必要なら権利者や専門家に確認してください。
